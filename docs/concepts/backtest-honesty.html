Concept 25 of 25 · Part F: Prove it

Backtest honesty

A backtest is only useful if it could not have known the future. Most ICT backtests online fail this test.

explained · code comingModule M13

The four rules

  1. No lookahead. Swings exist only after confirmation; MSS only at the close. The engine has a test that recomputes on every data prefix and fails if anything changes.
  2. Gaps. If price opens beyond your stop, you are filled at the open, not at your stop.
  3. Indian costs. STT 0.1% each side on delivery, stamp duty on buys, exchange fees, SEBI fee, GST on charges, and slippage.
  4. Ablation. Run with each ICT component off in turn. If removing 'order blocks' does not hurt results, order blocks are not adding edge.
Exact rule in the engine
tests/test_swings.py::test_no_lookahead_* : prefix-recompute equality on synthetic and NIFTY data
costs: block in config.yaml
Ablation: one run per toggle, reported side by side
Common mistakes
  • Backtesting on charts where you can see what happened next.
  • Ignoring costs: at 20 round trips a year, STT alone is about 4% of position value.
Exercise

Run pytest -q and read tests/test_swings.py. Then break the rule on purpose (set fractal_right to 0) and watch the lookahead test fail.
