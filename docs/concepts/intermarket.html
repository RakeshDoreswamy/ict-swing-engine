Intermarket and yields

Background context only. These never trigger a trade; they can make you more cautious or confirm a bias.

Exact rule in the engine
Each input is a toggle in config (bias.use_intermarket, bias.use_yields), off by default.
When on, the reading is logged with every signal so the backtest can test whether it helped.
Common mistakes
  • Turning background into a signal. These are filters, not triggers.
  • Over-fitting: if you add 7 filters, you will always find a reason not to trade, or to trade.
Exercise

For one month, write the 7 readings each Monday next to NIFTY's weekly move. Do any line up?
