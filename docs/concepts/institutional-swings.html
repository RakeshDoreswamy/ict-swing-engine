Concept 2 of 25 · Part A: Where is the liquidity?

Institutional swings (ITH / LTH)

Not all swings are equal. A swing that stands out against its neighbouring swings is where larger players act.

coded · learn command availableModule M1

The idea

ICT's 'Defining Institutional Swing Points' lesson ranks swings in three tiers. The trick is that the same 3-point test is applied again, but to the list of swings instead of the list of bars.

Exact rule in the engine
ITH: an STH whose previous STH and next STH are both LOWER
LTH: an ITH whose previous ITH and next ITH are both LOWER
ITL / LTL mirror this on lows.
ITH confirmed when the NEXT STH is confirmed; LTH when the next ITH is confirmed.

How to spot it

  1. List the short-term highs in order: e.g. 103, 105, 104, 108, 106.
  2. A value higher than both neighbours in that list is an ITH: here 105 and 108.
  3. Now list the ITHs (105, 108, …) and repeat: a value higher than both neighbouring ITHs is an LTH.

The delay is the lesson

An ITH needs the next STH to exist, which can take days. An LTH can take weeks. The higher the tier, the more reliable, and the later you know. A strategy that uses LTHs 'as they form' is using information it did not have. The engine stores a separate confirmation date for each tier and the swings_as_of() view only shows what was known then.

How a swing trader uses each tier

TierUse
STH / STLEntry timing: the MSS trigger, tight stops.
ITH / ITLThe dealing range, stops and first targets for a daily swing trade.
LTH / LTLMajor turning points, weekly bias, final targets.
Common mistakes
  • Calling every big-looking peak an ITH. If it is not higher than the STH on both sides, it is not.
  • Forgetting that a swing can be promoted later: today's STH may be next week's ITH.
Exercise

On NIFTY daily, take your STH list from the previous page and circle the ITHs. Then run python -m scripts.learn swings --bars 120 and read STEP 2, which shows each promotion and the date it became known.
