Entry models: limit vs stop

Two ways into the same setup. ICT's long-term trader lessons cover both; the engine runs them side by side so you can see which works better for you.

Exact rule in the engine
Limit: expires after limit_expiry_bars if not filled
Stop-loss: beyond the sweep extreme or the zone, + stop_buffer_atr × ATR
Target: next opposing liquidity pool
Reject if (target − entry) / (entry − stop) < min_rr (1.5)
Common mistakes
  • Moving a limit order to 'chase' after price leaves without you.
  • Placing the stop at the exact sweep low, where the next sweep will take it.
Exercise

For 3 historical setups, write both entries with stop, target and R:R. Which model would have filled? Which made more R?
