Pre-trade checklist and grading

The checklist turns the setup progression into booleans. Every no is a reason to skip, and skipped setups are logged too.

explained · code comingModule M12

Try it

Exact rule in the engine
grade = A if all 12 are true; B if 10–11; C otherwise
Only A is traded. B and C are written to the journal as 'skipped' with the missing lines.

Logging skipped setups matters: after 3 months you can check whether your B-grade skips would have worked. If they would have, a rule is too strict.

Common mistakes
  • Ticking a box because you want the trade.
  • Not logging skips, so you can never test the checklist itself.
